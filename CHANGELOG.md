## [Unreleased]

### Added

- Initial project scaffold and workspace structure
- uds-core: shared types, errors, config, constants
- Binary wire protocol specification
- Transport layer traits and serial implementation
- Device layer traits and ESP32 adapter
- CLI scaffold with clap derive
- C, Python, Node.js, TypeScript, Go, C#, Java, Kotlin, Swift binding stubs
- Firmware SDK ports for ESP32, ESP8266, STM32, RP2040, Arduino
- Plugin system with stable ABI
- OTA update mechanism
- Dashboard web application (beta)
- Comprehensive test suite and CI/CD pipelines
