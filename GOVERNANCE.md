# Governance

## Maintainers

The UDS project is governed by a core team of maintainers responsible for:

- Reviewing and merging pull requests
- Setting project roadmap and priorities
- Managing releases
- Enforcing the code of conduct

## Decision Making

Major decisions (API changes, new features, release timing) are made by
consensus among core maintainers. Lighter decisions (bug fixes, documentation)
follow standard PR review flow.

## Contributors

Anyone may contribute via pull request. Contributors who demonstrate sustained,
high-quality contributions may be invited to join the core team.
