# Examples

All examples are in the `examples/` directory.

| Example | Language | Description |
|---------|----------|-------------|
| `rust/hello-world` | Rust | Simple RPC client |
| `c/minimal` | C | Minimal C client |
| `python/device-control` | Python | Read sensor data via UDS |
| `esp32/basic-rpc` | C (ESP-IDF) | ESP32 firmware with UDS server |
| `stm32/blinky` | C (STM32 HAL) | LED control via RPC |
| `arduino/uds-client` | C++ (Arduino) | Arduino UDS client |
| `plugins/custom-transport` | Rust | CAN transport plugin |
| `dashboard/custom-widget` | JS/TS | Custom dashboard widget |

Each example has its own README with build and run instructions.
