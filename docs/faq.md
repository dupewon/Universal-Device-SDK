# FAQ

## Does UDS work offline?

Yes. UDS is local-first. All features work without internet access. Cloud services are optional add-ons.

## Which microcontrollers are supported?

ESP32, ESP8266, STM32, RP2040, and Arduino. More targets can be added via device adapters or plugins.

## Can I use UDS without Rust?

Yes. The CLI and core are written in Rust, but you interact through the `uds` command. Language bindings are available for C, C++, Python, Node.js, TypeScript, Go, C#, Java, Kotlin, and Swift.

## Is UDS production-ready?

UDS is under active development. Phase 4 (v1.0) targets production readiness with a security audit and performance optimization pass.
